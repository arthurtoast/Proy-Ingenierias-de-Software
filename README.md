# Proyecto de Ingeniería de Software — Buscador de documentos HTML

Proyecto del curso CS13309: construcción por etapas de un buscador sobre un
corpus de documentos HTML. Cada actividad vive en su propia carpeta.

| Actividad | Contenido | Estado |
|---|---|---|
| [actividad1](actividad1/) | Apertura de los archivos HTML y medición de tiempos de lectura | Terminada |

**Lenguaje:** Python 3 (biblioteca estándar, sin dependencias externas).

Las instrucciones de ejecución y las decisiones de diseño de cada etapa están en
el README de su carpeta.
